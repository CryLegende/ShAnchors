## Présentation

Plugin du serveur SkyHand.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shanchors` | — | Commandes du plugin SHAnchors | `shanchors.give` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shanchors.give` | Permet de donner des ancres de téléportation | `op` |
| `shanchors.bypass` | Permet dy bypass la protection d'île | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`

## Compilation

Java 21 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
