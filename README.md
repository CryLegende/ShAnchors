## Présentation

Ancres de téléportation à poser et à lier entre elles : s'accroupir sur une ancre téléporte à l'autre.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shanchors` | — | Commandes du plugin SHAnchors | `shanchors.give` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shanchors.give` | Permet de donner des ancres de téléportation | `op` |
| `shanchors.bypass` | Permet dy bypass la protection d'île | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`). Cliquez sur un fichier pour l'ouvrir :

<pre>
plugins/ShAnchors/
└── <a href="src/main/resources/config.yml">config.yml</a>
</pre>

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
